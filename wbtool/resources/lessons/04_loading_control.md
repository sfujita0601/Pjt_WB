# 4. ローディングコントロール（loading control）の意味

## (1) 何を理解するか

- ローディングコントロールで割る目的と、本アプリの正規化の段階（①〜③、必要に応じて ④ log2）の式を説明できる。
- 分母（ローディングコントロール の S）のばらつきや誤差が、比にどう伝わるかを理解する。
- 「ローディングコントロール で割れば正しい」とは限らない理由（線形性・飽和・発現変動）を説明できる。
- 正規化した値の誤った解釈を避けられる。

## (2) 導入

各レーンに同じ量のタンパク質を載せたつもりでも、実際には定量誤差やピペッティング、転写効率のむらによって、レーンごとに載った量は少しずつ違います。そこで、どの試料でも量がほぼ一定だと期待されるタンパク質（β-actin、GAPDH、α-tubulin など）や総タンパク質染色を **ローディングコントロール** として測り、目的タンパク質（Target）の S をそれで割ります。リン酸化タンパク質では、phospho 体を total 体で割ることもあります。

生物学的反復（biological replicate）は独立に用意した個体・培養など、技術的反復（technical replicate）は同じ試料を複数レーンに流した繰り返しです（5 章）。対照群を1とした相対値（fold change）は、対照群の平均で割った値です。

ただし、この割り算が意味を持つのは、次の前提が成り立つときだけです。

- ローディングコントロール の量が、実験条件（処理・群）によって変化しない。
- Target と ローディングコントロール の**両方**が、信号がタンパク質量に比例する範囲（線形範囲）で測られている。
- 同じ試料（同じ sample_id）の Target と ローディングコントロール を対応づけている。

## (3) 直感

- レーン 2 に 1.2 倍の量を載せてしまったら、Target も ローディングコントロール も 1.2 倍に写るはず。割れば 1.2 倍は打ち消される。
- でも、ローディングコントロール のバンドが濃すぎて飽和していると、本当は 1.2 倍でも 1.0 倍にしか写らない。すると打ち消しに失敗し、むしろ誤差を持ち込む。
- 分母は「ものさし」。ものさし自体がぶれると、割った値もぶれる。
- 処理によって ローディングコントロール 自体が増減するなら（例：代謝を変える処理で GAPDH が変わる）、割ることで偽の変化が生まれる。

## (4) 数式・原理

本アプリの正規化（wbtool/core/normalize.py と同じ順序）：

```
① sample_id ごとに   比 R = S(Target) ÷ S(ローディングコントロール)
② 同じ群・同じ生物学的反復内の技術的反復の R を算術平均
                     → 生物学的反復の値 R_bio
③ fold（対照群を1とした相対値）= R_bio ÷ (対照群の R_bio の平均)
④ （選択時）log2_ratio = log2(R_bio)。R_bio が正のときだけ計算する
```

- ① の分母が 0 以下・欠損・対応不明のときは比を計算せず、理由を status 列に表示します。分子が 0 以下のときは計算しますが注意を出します。
- ③ は全員を同じ定数で割るだけなので、対照群の fold の平均は 1 になります（対照群の各値は 1 の周りにばらつきます）。
- ④ の log2 は 5 章で扱います。

分母の誤差が比に伝わる目安（誤差が小さく、互いに独立な場合の近似）：

```
CV(R) ≈ √( CV(Target)² + CV(ローディングコントロール)² )
```

例えば Target と ローディングコントロール の測定誤差がどちらも 10 % なら、比の誤差はおよそ √(0.1² + 0.1²) ≈ 0.14、つまり約 14 % です。割り算は誤差を消すのではなく、**足し合わせる**方向に働きます。それでも割るのは、ロード量の違いという、より大きな系統的なずれを打ち消したいからです。

線形性：S = k × (量) が成り立つとき

```
R = k_T × (Target 量) ÷ ( k_L × (LC 量) ) = (k_T ÷ k_L) × (Target 量 ÷ LC 量)
```

k_T ÷ k_L は同じ膜・同じ露光なら共通の定数なので、比の**相対的な違い**は量の違いを反映します。ローディングコントロール が飽和していると k_L が一定ではなくなり、この式が崩れます。S の絶対値や R の値そのもの（例えば 0.30）には物理的な意味はありません。

## (5) 具体例

**教材用合成データ**（実験由来ではありません）。Control 2 試料（C1, C2）と Treated 2 試料（X1, X2）、各 1 レーン。S は背景補正後の値とします。

| sample_id | 群 | S(Target) | S(LC) | ① R | ③ fold |
|---|---|---|---|---|---|
| C1 | Control | 12000 | 40000 | 0.3000 | 0.980 |
| C2 | Control | 10000 | 32000 | 0.3125 | 1.020 |
| X1 | Treated | 18000 | 30000 | 0.6000 | 1.959 |
| X2 | Treated | 13500 | 22500 | 0.6000 | 1.959 |

```
対照群の R の平均 = (0.3000 + 0.3125) ÷ 2 = 0.30625
fold(X1) = 0.6000 ÷ 0.30625 ≈ 1.959
```

（この例は各生物学的反復に技術的反復が 1 つなので、② では値は変わりません。）

**割らずに Target だけ比べると**：Treated の平均 15750、Control の平均 11000 で 15750 ÷ 11000 ≈ 1.43 倍。Treated の試料はロード量が少なめ（S(LC) が小さい）だったため、Target だけを見ると差を過小評価します。

**ローディングコントロール が飽和していたら**：仮に、この露光では S(LC) が 32000 で頭打ちになり、C1 の S(LC) が 40000 ではなく 32000 と測られたとします。

| sample_id | S(LC) 測定値 | R | fold |
|---|---|---|---|
| C1 | 32000（頭打ち） | 0.375 | 1.091 |
| C2 | 32000 | 0.3125 | 0.909 |
| X1 | 30000 | 0.600 | 1.745 |
| X2 | 22500 | 0.600 | 1.745 |

Treated の fold は 1.96 から 1.75 に下がり、Control 内のばらつきも大きくなりました。分母の飽和は、比のどこに影響するか予想しにくい誤差を生みます。この例は頭打ちの値を仮定した教材用の計算です。実際の飽和がどのように起こるかは画像だけでは分かりません（6 章）。

（数値は Python で検算済み）

## (6) 小問

**問 1.** 試料 A：S(Target) = 9000、S(LC) = 30000。試料 B：S(Target) = 15000、S(LC) = 25000。A を対照（対照群は A のみ）としたとき、B の fold を求めなさい。

**問 2.** 「GAPDH で割ったら Treated の fold が 2.0 になった。だから Treated では Target タンパク質が 2 倍に増えた」と結論するには、どんな前提が必要ですか。3 つ挙げなさい。

**問 3.** S(LC) が −500 になった試料があります。本アプリはこの試料の比をどう扱いますか。また、何を確認すべきですか。

## (7) 解答・解説

**問 1.**

```
R(A) = 9000 ÷ 30000 = 0.30
R(B) = 15000 ÷ 25000 = 0.60
fold(B) = 0.60 ÷ 0.30 = 2.0
```

**問 2.** 例えば次のような前提が必要です。

- GAPDH の量が処理によって変わらないこと（変わるなら別の ローディングコントロール や総タンパク質染色を検討）。
- Target と GAPDH の両方が線形範囲で測られていること（希釈系列などで確認）。
- 同じ sample_id のバンドどうしを割っていること。ローディングコントロールの取り方（同じ膜の再プローブ、膜の切り分け、別の膜）を記録し、別の膜なら前提が弱いことを認識していること（本アプリは別の膜だと警告します）。
- 十分な数の生物学的反復があり、適切な統計解析をしていること（5 章）。

さらに、fold 2.0 は「画像上の相対強度の比」です。タンパク質の絶対量が 2 倍であることを直接示すものではありません。

**問 3.** 分母が 0 以下なので比を計算せず（欠損扱い）、status 列に理由を表示します。0 に丸めたり、勝手に除外したりはしません。ローディングコントロール のバンドが見えているか、背景 ROI がバンドにかかっていないか、極性設定が正しいかを確認し、判断と理由を記録します。

**このアプリでの操作：** ［正規化］画面でタンパク質の役割（Target／ローディングコントロールなど）を設定し、分子（Target）と分母（ローディングコントロール）、対照群を選ぶと、①〜④ の各段階の値が表で確認できます。対応表で各試料に分子・分母のバンドがそろっているか、分母に問題がある試料は「状態」列を見てください。
