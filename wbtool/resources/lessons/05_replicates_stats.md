# 5. Biological / technical replicate と統計解析

## (1) 何を理解するか

- biological replicate と technical replicate の違いを説明し、統計の n を正しく数えられる。
- technical replicate を独立な n として数える（擬似反復）と、p 値が不当に小さくなることを数値で確認する。
- 本アプリで使える検定（Welch の t 検定、対応のある t 検定）の使い分けと前提を理解する。
- p 値だけでなく、効果量・信頼区間・n を併せて報告する理由を説明できる。

## (2) 導入

統計検定が答えるのは「群の違いが、独立な試料どうしのばらつきに比べて大きいか」という問いです。そのため、**何を独立な単位とみなすか**が結果を大きく左右します。

| 種類 | 例 | 何のばらつきを表すか |
|---|---|---|
| biological replicate | 別のマウス、別の日に独立に培養・処理した細胞 | 生物学的なばらつき（結論を一般化したい対象） |
| technical replicate | 同じライセートを 2 レーンに載せる、同じ膜を 2 回スキャン | 測定操作のばらつき |
| 同じ膜の別露光 | 同じ膜の 30 秒露光と 2 分露光 | 反復ではない（どちらか 1 枚を選ぶ） |

本アプリでは、各 sample_id に group（群）、bio_rep（biological replicate ID）、tech_rep（technical replicate ID）を入力します。統計の解析単位は biological replicate で、technical replicate は 4 章の正規化 ② で平均されてから検定に渡ります。bio_rep が未入力の行があると、独立な単位が分からないため検定を実行しません。

## (3) 直感

- 同じライセートを 3 レーンに載せても、分かるのは「ピペットとブロットの再現性」だけ。「処理が効くかどうか」についての情報は、マウス 1 匹分しか増えていない。
- technical replicate を n に数えると、n が見かけ上増え、しかも同じ試料由来の値は似ているのでばらつきが小さく見える。両方の理由で p 値が小さくなりすぎる。
- 同じ個体・同じ実験日の Control と Treated が組になっているなら、組ごとの差を見る方が日ごとの変動を除けて検出力が上がる（対応のある t 検定）。

## (4) 数式・原理

記述統計（biological replicate の値 x_1 … x_n について）：

```
平均   m  = Σ x_j ÷ n
標準偏差 SD = √( Σ (x_j − m)² ÷ (n − 1) )
95% CI = m ± t(0.975, n − 1) × SD ÷ √n
```

Welch の t 検定（独立 2 群 A, B、等分散を仮定しない）：

```
t  = (m_B − m_A) ÷ √( SD_A²/n_A + SD_B²/n_B )
自由度 df（Welch–Satterthwaite の式）
  = (SD_A²/n_A + SD_B²/n_B)² ÷ [ (SD_A²/n_A)²/(n_A − 1) + (SD_B²/n_B)²/(n_B − 1) ]
```

効果量は Hedges の g（プール SD 基準、小標本補正あり）を表示します。

対応のある t 検定（同じ bio_rep ID の組 k = 1 … n の差 d_k = B_k − A_k）：

```
t   = 平均(d) ÷ ( SD(d) ÷ √n )      df = n − 1
d_z = 平均(d) ÷ SD(d)                （効果量）
```

使い分けと前提：

| 状況 | 検定 | 主な前提 |
|---|---|---|
| 2 群が独立（別々の個体） | Welch の t 検定 | 独立性、各群がおおむね正規分布 |
| 2 群が組になっている（同じ個体・同じ実験日） | 対応のある t 検定 | 組の対応が正しい、差がおおむね正規分布 |
| 3 群以上、二要因、反復測定など | ANOVA・多重比較・混合効果モデル | **本アプリでは Phase 2（未実装）**。他の統計ソフトを使い、t 検定の繰り返しで代用しない |

fold は全値を同じ定数（Control 平均）で割った値なので、ratio で検定しても fold で検定しても p 値は同じです。比は右に裾を引く分布になりやすく、対数変換するかどうかは**データを見る前に**決めておきます（本アプリは自動で変換しません）。

## (5) 具体例

**教材用合成データ**（実験由来ではありません）。Control・Treated 各 3 biological replicate（R1〜R3）、それぞれ technical replicate 2 レーン（T1, T2）。Loading control の S はレーンごとに 16000〜24000 でばらつかせ、① の比 R が下表になるように Target の S を決めました。

| 群 | bio_rep | ① R（T1） | ① R（T2） | ② R_bio |
|---|---|---|---|---|
| Control | R1 | 1.00 | 1.10 | 1.05 |
| Control | R2 | 0.90 | 0.94 | 0.92 |
| Control | R3 | 1.06 | 1.00 | 1.03 |
| Treated | R1 | 1.60 | 1.70 | 1.65 |
| Treated | R2 | 1.30 | 1.38 | 1.34 |
| Treated | R3 | 1.92 | 1.84 | 1.88 |

Control 群の R_bio の平均は (1.05 + 0.92 + 1.03) ÷ 3 = 1.00 なので、この例では ③ の fold は R_bio と同じ値になります。

記述統計（fold、n = biological replicate の数）：

| 群 | n | 平均 | SD | 95% CI |
|---|---|---|---|---|
| Control | 3 | 1.000 | 0.070 | 0.826〜1.174 |
| Treated | 3 | 1.623 | 0.271 | 0.950〜2.296 |

**正しい解析（n = 3 vs 3、Welch の t 検定）**

```
差（Treated − Control） = 0.623、95% CI 0.001〜1.246
t = 3.86、df ≈ 2.27、p ≈ 0.050
Hedges の g ≈ 2.52
```

**誤った解析（technical replicate を独立とみなし n = 6 vs 6）**

```
t = 5.92、df ≈ 5.88、p ≈ 0.0011
```

同じデータなのに、n の数え方を誤っただけで p 値が約 45 分の 1 になりました。

**もし R1〜R3 が「同じ実験日に Control と Treated を並べて処理した組」なら**（対応のある t 検定）

```
差の平均 = 0.623、t = 5.00、df = 2、p ≈ 0.038、d_z ≈ 2.89
```

対応があるかどうかは**実験デザイン**で決まります。p 値が小さくなる方を後から選んではいけません。

正しい解析の p ≈ 0.050 は 0.05 付近で、信頼区間の下限もほぼ 0 です。「有意か否か」の二択で語るより、n = 3 では効果の大きさの推定がかなり不確かだと読むのが誠実です。

（数値は wbtool.core.normalize.normalize と wbtool.core.stats で検算済み）

## (6) 小問

**問 1.** マウス 4 匹（Control 2 匹、Treated 2 匹）の肝臓ライセートを、それぞれ 3 レーンずつ載せました。さらに同じ膜を 2 回露光しました。各群の n はいくつですか。

**問 2.** Control・Treated・Inhibitor の 3 群を比べたい学生が、本アプリで 2 群ずつ 3 回 Welch の t 検定を行おうとしています。何が問題ですか。

**問 3.** 上の具体例で、正しい解析の p 値（約 0.050）と誤った解析の p 値（約 0.0011）が大きく違う理由を 2 つ挙げなさい。

## (7) 解答・解説

**問 1.** 各群 n = 2 です。3 レーンは technical replicate（平均して 1 つの値にする）、2 回の露光は反復ではありません（飽和していない方を 1 枚選ぶ）。なお n = 2 では検定結果がきわめて不安定で、本アプリも注意を表示します。

**問 2.** 2 群比較を繰り返すと、少なくとも 1 回偶然に「有意」になる確率（第一種の過誤の全体の確率）が 0.05 を超えて大きくなります。3 群以上の比較には ANOVA と適切な多重比較を使いますが、これらは本アプリでは Phase 2（未実装）です。正規化済みの biological replicate の値を CSV で書き出し、統計ソフトで解析し、使った方法を記録してください。

**問 3.** (a) n が 3 から 6 に増えたように扱われ、標準誤差の分母 √n と自由度が大きくなった。(b) 同じライセート由来の 2 レーンは値が似ているので、群内のばらつきが実際の biological なばらつきより小さく見積もられた。どちらも p 値を小さくする方向に働きます。

**このアプリでの操作：** ［画像・試料情報］の試料表で group・bio_rep・tech_rep を入力し、［統計］画面で検定を選びます。結果には検定名・n・欠損数・効果量・95% CI と、検定の前提が一緒に表示されます。
