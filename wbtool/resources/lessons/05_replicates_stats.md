# 5. 生物学的反復・技術的反復と統計解析

## (1) 何を理解するか

- 生物学的反復（biological replicate）と技術的反復（technical replicate）の違いを説明し、統計の n を正しく数えられる。
- 技術的反復を独立な n として数える（擬似反復）と、p 値が不当に小さくなることを数値で確認する。
- 「対応あり」を決めるのは実験単位ID（subject_id）であり、同じ日・同じブロットというだけでは対応にならないことを説明できる。
- 3 群以上を 2 群ずつ t 検定で比べてはいけない理由（多重比較の問題）を説明できる。
- 「何を比べたいか」「独立か対応ありか」「分散の仮定」から手法を選べる（Welch の t 検定、対応のある t 検定、Welch ANOVA ＋ Games–Howell、一元配置 ANOVA ＋ Dunnett／Tukey）。
- log2 変換の意味（倍率を対称に扱う、幾何平均）と、0・負の値を変換しない理由を説明できる。
- p 値だけでなく、効果量・信頼区間・n を併せて報告する理由を説明できる。

## (2) 導入

統計検定が答えるのは「群の違いが、独立な試料どうしのばらつきに比べて大きいか」という問いです。そのため、**何を独立な単位とみなすか**が結果を大きく左右します。

| 種類 | 例 | 何のばらつきを表すか |
|---|---|---|
| 生物学的反復（biological replicate） | 別のマウス、別の日に独立に培養・処理した細胞 | 生物学的なばらつき（結論を一般化したい対象） |
| 技術的反復（technical replicate） | 同じライセートを 2 レーンに載せる、同じ膜を 2 回スキャン | 測定操作のばらつき |
| 同じ膜の別露光 | 同じ膜の 30 秒露光と 2 分露光 | 反復ではない（どちらか 1 枚を選ぶ） |

本アプリでは、各 sample_id に次を入力します。

| 列 | 意味 |
|---|---|
| group（群） | 比べたい条件 |
| bio_rep（生物学的反復） | 統計の n になる単位。群の中で一意 |
| tech_rep（技術的反復） | 同じ試料の繰り返し。n に数えず平均する |
| subject_id（実験単位ID） | 同じ個体・同じ試料を**複数の条件で測った**ときだけ、条件をまたいで同じ ID にする。対応のある検定に使う |
| batch_id（バッチID） | 実験日・ブロットなどのまとまり。記録用で、対応には使わない |

統計の解析単位は生物学的反復で、技術的反復は 4 章の正規化 ② で平均されてから検定に渡ります。bio_rep が未入力の行があると、独立な単位が分からないため検定を実行しません。

## (3) 直感

- 同じライセートを 3 レーンに載せても、分かるのは「ピペットとブロットの再現性」だけ。「処理が効くかどうか」についての情報は、マウス 1 匹分しか増えていない。
- 技術的反復を n に数えると、n が見かけ上増え、しかも同じ試料由来の値は似ているのでばらつきが小さく見える。両方の理由で p 値が小さくなりすぎる。
- 同じ個体を処理前と処理後で測ったなら、個体ごとの差を見る方が個体差を除けて検出力が上がる（対応のある t 検定）。ただし「対応」は**同じ実験単位を測ったこと**で決まる。同じ日に並べて処理した・同じブロットに載せたというだけでは、別の個体どうしなので対応ではない。
- 3 群を 2 群ずつ比べると検定は 3 回。1 回ごとに 5% の確率で「偶然の有意」が出るなら、3 回のうちどれかで出る確率はもっと大きい。だから比較の数に応じて p 値を調整する（多重比較）。
- 比は「2 倍」と「1/2 倍」が同じ大きさの変化。そのまま平均すると 2 倍の側に引っ張られる。log2 を取ると +1 と −1 になり、対称に扱える。

## (4) 数式・原理

記述統計（生物学的反復の値 x_1 … x_n について）：

```
平均     m   = Σ x_j ÷ n
標準偏差  SD  = √( Σ (x_j − m)² ÷ (n − 1) )
95% CI   = m ± t(0.975, n − 1) × SD ÷ √n
```

Welch の t 検定（独立 2 群 A, B、等分散を仮定しない）：

```
t  = (m_B − m_A) ÷ √( SD_A²/n_A + SD_B²/n_B )
自由度 df（Welch–Satterthwaite の式）
  = (SD_A²/n_A + SD_B²/n_B)² ÷ [ (SD_A²/n_A)²/(n_A − 1) + (SD_B²/n_B)²/(n_B − 1) ]
```

効果量は Hedges の g（プール SD 基準、小標本補正あり）を表示します。

対応のある t 検定（両群に共通する subject_id の組 k = 1 … n の差 d_k = B_k − A_k）：

```
t   = 平均(d) ÷ ( SD(d) ÷ √n )      df = n − 1
d_z = 平均(d) ÷ SD(d)                （効果量）
```

多重比較の必要性（有意水準 0.05 の検定を m 回、互いに独立と仮定した目安）：

```
少なくとも 1 回偶然に有意になる確率 = 1 − (1 − 0.05)^m
m = 3 のとき 1 − 0.95^3 = 0.143
```

3 群以上の比較は 2 段階で表示します。

```
全体検定：一元配置 ANOVA   F = [群間の平方和 ÷ (k − 1)] ÷ [群内の平方和 ÷ (N − k)]
          Welch ANOVA     各群を n_j ÷ 分散 で重み付けした F（等分散を仮定しない）
多重比較：Tukey（全群間）・Dunnett（対照群とだけ）… 群内分散をプールする（等分散を仮定）
          Games–Howell（全群間）              … 対ごとに Welch と同じ標準誤差（等分散を仮定しない）
η²（イータ二乗）= 群間の平方和 ÷ 全体の平方和  … 群の違いで説明されるばらつきの割合（参考値）
```

手法の選び方（本アプリの［統計］画面の ①〜③ の質問に対応）：

| 何を比べたいか | 独立か対応ありか | 分散の仮定 | 手法 |
|---|---|---|---|
| 2 群 | 独立 | 仮定しない | Welch の t 検定 |
| 2 群 | 対応あり（subject_id） | — | 対応のある t 検定 |
| 3 群以上：対照群と比べる | 独立 | 仮定しない（既定） | Welch ANOVA ＋ Games–Howell（対照群を含む対だけ表示。全対で調整するので保守的） |
| 3 群以上：対照群と比べる | 独立 | 等分散を仮定 | 一元配置 ANOVA ＋ Dunnett |
| 3 群以上：全ての群どうし | 独立 | 仮定しない（既定） | Welch ANOVA ＋ Games–Howell |
| 3 群以上：全ての群どうし | 独立 | 等分散を仮定 | 一元配置 ANOVA ＋ Tukey（Tukey–Kramer） |
| 3 群以上 | 対応あり（反復測定） | — | **本アプリでは未実装**（検定しない）。独立群の ANOVA で代用しない |

log2 変換（4 章の ④。生物学的反復の比 R が正のときだけ）：

```
log2_ratio = log2(R)
log2_fold  = log2_ratio − （対照群の log2_ratio の平均）
fold_geo   = 2^log2_fold      … 対照群の幾何平均を 1 とした相対値
log2 スケールの群間の差 d → 2^d が群間の幾何平均の比
```

- fold（対照群を1とした相対値、fold change）は全値を同じ定数（対照群の平均）で割った値なので、比で検定しても fold で検定しても p 値は同じです。同様に、log2_fold で検定しても log2_ratio と同じです。だから［統計］で選ぶ値は「正規化比」か「log2（正規化比）」です。
- 比で解析するか log2 で解析するかは、**データを見る前に**決めます（既定は比）。
- 比が 0 以下・欠損の値は log2 にできません。本アプリは 0.001 などの擬似値に置き換えず、log2 では検定しません。

## (5) 具体例

**例 1：n の数え方**（教材用合成データ。実験由来ではありません）

Control・Treated 各 3 生物学的反復（R1〜R3）、それぞれ技術的反復 2 レーン（T1, T2）。ローディングコントロール（loading control）の S はレーンごとに 16000〜24000 でばらつかせ、① の比 R が下表になるように Target の S を決めました。

| 群 | bio_rep | ① R（T1） | ① R（T2） | ② R_bio |
|---|---|---|---|---|
| Control | R1 | 1.00 | 1.10 | 1.05 |
| Control | R2 | 0.90 | 0.94 | 0.92 |
| Control | R3 | 1.06 | 1.00 | 1.03 |
| Treated | R1 | 1.60 | 1.70 | 1.65 |
| Treated | R2 | 1.30 | 1.38 | 1.34 |
| Treated | R3 | 1.92 | 1.84 | 1.88 |

対照群の R_bio の平均は (1.05 + 0.92 + 1.03) ÷ 3 = 1.00 なので、この例では ③ の fold は R_bio と同じ値になります。

記述統計（fold、n = 生物学的反復の数）：

| 群 | n | 平均 | SD | 95% CI |
|---|---|---|---|---|
| Control | 3 | 1.000 | 0.070 | 0.826〜1.174 |
| Treated | 3 | 1.623 | 0.271 | 0.950〜2.296 |

正しい解析（n = 3 vs 3、Welch の t 検定）：

```
差（Treated − Control） = 0.623、95% CI 0.001〜1.246
t = 3.86、df ≈ 2.27、p ≈ 0.050
Hedges の g ≈ 2.52
```

誤った解析（技術的反復を独立とみなし n = 6 vs 6）：

```
t = 5.92、df ≈ 5.88、p ≈ 0.0011
```

同じデータなのに、n の数え方を誤っただけで p 値が約 45 分の 1 になりました。

もし R1〜R3 が「同じ個体（同じ subject_id）から得た Control 条件と Treated 条件の試料」だったら（対応のある t 検定）：

```
差の平均 = 0.623、t = 5.00、df = 2、p ≈ 0.038、d_z ≈ 2.89
```

対応があるかどうかは**実験デザイン**で決まります。同じ日に処理しただけの別々の個体なら対応ではありません。p 値が小さくなる方を後から選んではいけません。

正しい解析の p ≈ 0.050 は 0.05 付近で、信頼区間の下限もほぼ 0 です。「有意か否か」の二択で語るより、n = 3 では効果の大きさの推定がかなり不確かだと読むのが誠実です。

（例 1 の数値は wbtool.core.normalize.normalize と wbtool.core.stats で検算済み）

**例 2：3 群の比較と多重比較**（教材用合成データ）

対照群を 1 とした値：Control = 0.90, 1.00, 1.10、DrugA = 1.20, 1.50, 1.80、DrugB = 1.60, 2.00, 2.40（各 n = 3）。群の分散は 0.01、0.09、0.16 で、最大 16 倍違います。

全体検定：

```
一元配置 ANOVA（等分散を仮定）：F(2, 6) = 8.65、p = 0.017、η² = 0.74
Welch ANOVA（等分散を仮定しない）：F(2, 3.07) = 9.66、p = 0.047
```

対照群との比較の p 値：

| 比較 | 差 | 調整なしの Welch t（誤り） | Games–Howell（既定） | Dunnett（等分散を仮定） |
|---|---|---|---|---|
| DrugA − Control | 0.5 | 0.090 | 0.166 | 0.140 |
| DrugB − Control | 1.0 | 0.042 | 0.079 | 0.011 |

- 2 群ずつ t 検定を繰り返すと DrugB は p = 0.042 ですが、多重性を調整した Games–Howell では p = 0.079 です。
- 等分散を仮定する Dunnett では p = 0.011 と小さくなります。群内分散をまとめて自由度を大きく取るためですが、この例のように分散が大きく違うと仮定が成り立ちません。
- このように手法で結論が変わり得るので、**どの手法を使うかはデータを見る前に**決めておきます。本アプリの既定は「等分散を仮定しない」です。

（例 2 の数値は wbtool.core.stats_multi の関数で検算済み）

**例 3：log2 と幾何平均**（教材用合成データ）

生物学的反復の比：Control = 0.40, 0.50, 0.625、Treated = 0.80, 1.00, 2.00

| 値 | Control | Treated |
|---|---|---|
| log2_ratio | −1.322, −1.000, −0.678 | −0.322, 0.000, 1.000 |
| 対照群の幾何平均を 1 とした値（fold_geo） | 0.80, 1.00, 1.25 | 1.60, 2.00, 4.00 |

```
算術平均の比     = 1.267 ÷ 0.508 = 2.49 倍
幾何平均の比     = 2^(log2 の平均差 1.226) = 2.34 倍
Welch の t 検定  比（線形）：p = 0.174    log2_ratio：p = 0.073
```

Treated の 2.00 という大きな値に、算術平均は強く引っ張られます。線形と log2 で p 値も変わるので、どちらで解析するかは事前に決めます。

（例 3 の数値は wbtool.core.normalize.normalize と SciPy で検算済み）

**問 3.** 上の例 1 で、正しい解析の p 値（約 0.050）と誤った解析の p 値（約 0.0011）が大きく違う理由を 2 つ挙げなさい。

**問 5.** ある生物学的反復の比が −0.02（分子のバンドが背景より弱い）になりました。log2 で解析したいので、この値を 0.001 に置き換えて log2 を取ってもよいですか。

## (7) 解答・解説

**問 1.** 各群 n = 2 です。3 レーンは技術的反復（平均して 1 つの値にする）、2 回の露光は反復ではありません（飽和していない方を 1 枚選ぶ）。なお n = 2 では検定結果がきわめて不安定で、本アプリも注意を表示します。

**問 2.** ①「3 群以上：それぞれの処理群を対照群と比べたい」、②「独立」を選びます。分散が等しいと仮定する根拠がなければ「等分散を仮定する」はオフのままにし、Welch ANOVA ＋ Games–Howell（対照群を含む対だけを表示、全対で調整するので保守的）になります。等分散を仮定してよい根拠を事前に持っているなら、一元配置 ANOVA ＋ Dunnett です。2 群ずつ t 検定を繰り返すと、少なくとも 1 回偶然に有意になる確率が 0.05 より大きくなります（3 回なら目安で約 0.14）。

**問 3.** (a) n が 3 から 6 に増えたように扱われ、標準誤差の分母 √n と自由度が大きくなった。(b) 同じライセート由来の 2 レーンは値が似ているので、群内のばらつきが実際の生物学的なばらつきより小さく見積もられた。どちらも p 値を小さくする方向に働きます。

**問 4.** subject_id は「同じ個体・同じ試料を複数の条件で測った」ことを示す ID です。Control のマウスと Treated のマウスは別の個体なので、対応はありません。同じ ID を入れると、別々の個体を同じ実験単位とみなすことになります。この設計は独立 2 群（Welch の t 検定）で解析し、実験日・ブロットの情報は batch_id に記録します。

**問 5.** いけません。置き換える値（0.001、0.01、最小値の半分など）の選び方で log2 の値が大きく変わり、結果が恣意的になります。また「背景より弱い」という情報が失われます。本アプリは擬似値に置き換えず、log2 では検定しません。比（線形スケール）で解析するか、そのバンドの背景・極性・ROI を見直し、判断と理由を記録します。

**このアプリでの操作：** ［画像・試料情報］の試料表で group・bio_rep・tech_rep と、必要なら subject_id・batch_id を入力します。［統計］画面で ① 何を比べたいか、② 独立か対応ありか、③ 検定に使う値（と分散の仮定）、④ 比べる群 を選ぶと、手法が決まります。割当て表を確認してチェックを入れると、検定名・n・欠損数・効果量・95% CI（3 群以上では調整済み p と同時信頼区間）と、検定の前提が表示されます。教材用サンプルの「3群」で多重比較を試してみましょう。
