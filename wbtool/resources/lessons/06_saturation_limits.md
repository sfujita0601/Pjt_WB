# 6. 過露光・飽和・スキャナーの限界

## (1) 何を理解するか

- 飽和（信号の頭打ち）が S をどのように過小評価させるかを説明できる。
- 画像解析で**検出できること**（端値の画素の集中など）と、**検出できないこと**（端値に達していない非線形性など）を区別できる。
- 本アプリの QC 警告は「疑い」であって確定診断ではないこと、線形範囲は実験で確認するしかないことを理解する。

## (2) 導入

信号の「頭打ち」は、Western blot のいくつもの段階で起こり得ます。

| 段階 | 頭打ちの例 | 画像から分かるか |
|---|---|---|
| 抗体・基質 | 抗原が多すぎて抗体が足りない、基質が局所的に消費される | 分からない |
| フィルム | 露光が長すぎて銀粒子が最大限に黒化する、特性曲線の肩で応答が鈍る | 端値に達すれば疑える。手前の鈍りは分からない |
| スキャナー | 最も暗い部分が 0 に張りつく、自動補正で白や黒が切り詰められる | 端値に達すれば疑える |
| 画像の保存 | 8-bit への変換、JPEG 圧縮 | 形式は分かる。失われた情報は戻らない |

画像に記録された時点で、頭打ちした部分の情報は失われています。画像処理で「元の信号」を復元することはできません。

## (3) 直感

- 8-bit 画像では、どんなに黒いバンドも画素値 0 より暗くはなれない。本当は「もっと濃い」バンドでも 0 で止まる。
- 飽和したバンドは、中心が平らに 0 に張りつき、プロファイルでは谷の底が平らになる。これは画像から**疑う**ことができる。
- しかし、フィルムの応答がじわじわ鈍っていく段階（まだ 0 に達していない）では、画素値はもっともらしい中間の値をとる。画像を見ても、比例しているのかどうかは分からない。
- だから、露光時間を変えた複数のフィルムや希釈系列を使い、信号が量に比例して増えることを**実験で**確かめる必要がある。

## (4) 数式・原理

本アプリの QC が数えるもの（wbtool/core/qc.py）：

```
画像全体：  画素値 = 0 の割合、画素値 = dtype の最大値 の割合
            どちらかが 0.1 % を超えたら「飽和・黒つぶれ候補」「飽和・白飛び候補」として警告
バンド ROI 内：暗いバンドなら画素値 = 0 の画素数、明るいバンドなら最大値の画素数
            1 個以上あれば「飽和候補（バンド内）」として警告
```

飽和による過小評価：背景 b、真の深さ a（背景からの暗さ）の暗いバンドで、画素値は 0 より小さくなれないので

```
記録される深さ = min(a, b)       (8-bit・暗いバンドの場合)
S_測定 = N × min(a, b)    ≤    S_真 = N × a
```

線形性の確認：量 q を段階的に変えた希釈系列で S(q) を測り、S が q にほぼ比例する範囲（線形範囲）を確認します。この確認は画像 1 枚の画素値分布からはできません。露光時間・希釈系列の比較機能は本アプリでは Phase 2（未実装）です。

## (5) 具体例

**教材用合成データ**（実験由来ではありません）。8-bit、背景 220、ROI は 22 × 10 = 220 画素、近傍背景で補正。

**例 1：端値に達する飽和**（真の深さ 100, 200, 300）

| バンド | 真の S | 測定 S | ROI 内の画素値 0 の数 | QC |
|---|---|---|---|---|
| 1（深さ 100） | 22000 | 22000 | 0 | 警告なし |
| 2（深さ 200） | 44000 | 44000 | 0 | 警告なし |
| 3（深さ 300） | 66000 | 48400 | 220 | 飽和候補（バンド内） |

バンド 3 は背景 220 より深くは暗くなれないので、深さ 220 に切り詰められました（220 × 220 = 48400）。真の比 3 : 1 に対し、測定の比は 48400 ÷ 22000 = 2.2 です。

**例 2：同じバンドにぼやけ（σ = 1.5）を加えた場合**

| バンド | 測定 S | 画素値 0 の数 |
|---|---|---|
| 1 | 18420 | 0 |
| 2 | 36820 | 0 |
| 3 | 45860 | 156 |

ぼやけるとバンドの縁は 0 に達しないので、0 の画素は一部（156 個）だけになります。それでも 1 個以上あるので QC は警告します。

**例 3：端値に達しない非線形性（検出できない例）**

真の深さを 40, 80, 120, 160（比 1 : 2 : 3 : 4）とし、仮に「フィルムの応答が深さ = 200 × (1 − e^(−a/150)) のように鈍る」と**仮定**します（説明用の架空のモデルで、実際のフィルムの特性曲線ではありません）。画像に記録される深さは約 47, 83, 110, 131 になり、

| バンド | 測定 S | 1 本目との比 | 真の比 | 画素値 0 の数 |
|---|---|---|---|---|
| 1 | 10340 | 1.00 | 1 | 0 |
| 2 | 18260 | 1.77 | 2 | 0 |
| 3 | 24200 | 2.34 | 3 | 0 |
| 4 | 28820 | 2.79 | 4 | 0 |

どの画素も端値に達していないので、本アプリの QC は**何も警告しません**。それでも比は大きく歪んでいます。これが「画像解析だけでは線形性を証明できない」ことの具体的な意味です。

（数値は make_blot・estimate_background・measure_band で検算済み）

**画像解析で検出できること／できないこと**

| 検出できる（疑いとして） | 検出できない |
|---|---|
| 画素値が 0 や最大値に張りついた画素の集中 | 端値に達していないフィルム・スキャナーの非線形応答 |
| ROI の不一致・重なり、背景 ROI とバンドの交差 | 抗体や基質の頭打ち |
| JPEG 形式、カラーからの変換 | スキャナーの自動補正がかかったかどうか（記録がなければ） |
| 負の補正値 | Loading control が処理で変動したかどうか |

## (6) 小問

**問 1.** 8-bit、背景 200 の画像で、暗いバンドの真の深さが 250 だとします。ROI は 100 画素で、ぼやけはありません。真の S と測定される S を求めなさい。

**問 2.** QC で飽和の警告が 1 つも出なかった。「このデータは線形範囲で測られている」と言えますか。

**問 3.** 長時間露光のフィルムでは Target のバンドがよく見えるが一部が 0 に張りつき、短時間露光ではバンドが薄いが張りつきはない。どちらを定量に使いますか。両方使ってはいけないのはなぜですか。

## (7) 解答・解説

**問 1.**

```
真の S   = 100 × 250 = 25000
測定の S = 100 × min(250, 200) = 100 × 200 = 20000
```

画素値は 0 より小さくなれないので、深さは 200 で頭打ちになります。ROI 内の 100 画素すべてが 0 になり、QC は飽和候補として警告します。

**問 2.** 言えません。QC が見ているのは端値の画素だけです。具体例 3 のように、端値に達していなくても応答が非線形なら比は歪みます。線形範囲は、希釈系列や露光時間を変えた比較によって**実験的に**確認する必要があります。

**問 3.** 原則として張りつきのない短時間露光を使います（背景からはっきり区別できることも確認します）。同じ膜の別露光は独立な反復ではないので、両方を「定量に使う」にすると同じ試料を二重に数えることになります。本アプリの QC は、同じ膜・同じタンパク質で複数の画像が「定量に使う」になっていると警告します。

**このアプリでの操作：** ［QC］画面で飽和候補の警告を確認し、採用・除外・再撮影推奨などの判断と理由を記録します。学生向けチェックリストで、露光の選び方やスキャナーの自動補正の設定も確認しましょう。
