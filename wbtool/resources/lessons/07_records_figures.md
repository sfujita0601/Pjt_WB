# 7. 実験記録と Figure 作成

## (1) 何を理解するか

- 原画像を変更せずに保存し、定量は常に原画像で行う理由を説明できる。
- 明るさ・コントラスト・ガンマの変更が、定量値にどう影響するかを数値で理解する。
- 解析を他人（未来の自分を含む）が再現できるために、何を記録すべきかを挙げられる。
- 個々のデータ点・n・誤差の種類を明示した、誠実な Figure を作れる。
- SD・SEM・95% 信頼区間の違いを説明し、図の説明文（Figure legend）に何を書くべきか分かる。
- バンド画像を Figure 用に切り出すときの誠実な扱い（連続した領域、並べ替え・継ぎ合わせをしない、線形表示、記録を残す）を説明できる。

## (2) 導入

論文や発表の Western blot の図と定量グラフは、読み手が「元のデータで何が起きたか」を判断するための証拠です。そのため、多くの学術誌は画像の取り扱いについて規定を設けています。代表的なものは次のとおりです。

- 原画像（未処理のスキャン画像・フィルム）を保存し、求められたら提出できるようにする。
- 明るさ・コントラストの調整は画像全体に均一にかけ、背景を消したりバンドを強調したりするような局所的な処理をしない。
- 別の膜・別の露光・レーンの並べ替えを 1 枚の図に組み合わせる場合は、境界線などで明示し、方法に記載する。

これは「不正をしない」ためだけでなく、自分の解析を後から検証できるようにするためでもあります。半年後に「この S はどの画像の、どの測定領域（ROI）から、どの背景法で出したのか」を答えられなければ、その数値は使えません。

## (3) 直感

- 表示の明るさやコントラストを変えるのは、見やすくするため。定量は原画像の数値で行うので、表示を変えても S は変わらない（本アプリはこの 2 つを分けている）。
- ところが、コントラストを調整した画像を**保存して**、それを定量に使うと話が変わる。直線的な調整なら比は保たれることもあるが、ガンマ補正や切り詰め（白飛び・黒つぶれ）が入ると比が歪む。
- 平均値の棒グラフだけでは、n = 3 なのか n = 30 なのか、外れ値があるのか分からない。個々の点を描けば一目で分かる。
- エラーバーは「何のバーか」で意味がまったく違う。SD はデータのばらつき、SEM は平均の推定精度、95% 信頼区間は平均の区間推定。同じデータでも長さが大きく違うので、種類を書かないエラーバーは読めない。
- 見栄えのよいレーンだけを切り貼りすると、読み手は「1 枚の膜をそのまま見ている」と誤解する。切り出すなら連続した範囲をそのまま使い、別の画像・別の膜の境界は見せる。

## (4) 数式・原理

画素値の変換 p' = f(p) をかけた画像で定量すると（暗いバンド、背景 b）：

```
直線的な変換  f(p) = α × p + β（切り詰めなし、α は正）のとき
  S' = −Σ (f(p_i) − f(b)) = α × S
  → すべてのバンドの S が同じ α 倍になるので、比は変わらない

ガンマ補正   f(p) = 255 × (p / 255)^γ  （γ ≠ 1）
  → 曲がった変換なので、背景からの差の縮み方がバンドの濃さによって違い、比が変わる

切り詰め     f(p) が 0 未満や 255 超えになる部分を 0 や 255 に丸める
  → 頭打ち（6 章と同じ）が人工的に生じ、比が変わる
```

エラーバーの 3 種類（生物学的反復（biological replicate）の値 x_1 … x_n、平均 m）：

```
SD（標準偏差）      = √( Σ (x_j − m)² ÷ (n − 1) )     … データのばらつき
SEM（標準誤差）     = SD ÷ √n                          … 平均の推定精度（n が増えると小さくなる）
95% 信頼区間の幅    = t(0.975, n − 1) × SD ÷ √n       … 平均の区間推定
図に描くのは m ± 上のどれか。どれを描いたかを必ず説明に書く
```

図の説明文（Figure legend）に入れるべき要素（本アプリは自動で下書きを作ります）：

```
・縦軸の値（例：対照群を 1 とした相対値（fold change））
・点が何か（個々の生物学的反復）と、中心とエラーバーの種類（平均 ± SD など）
・各群の n と、その単位（生物学的反復。技術的反復（technical replicate）は平均した）
・正規化（分子 ÷ 分母、対照群）
・検定法と、p 値が調整済みかどうか（3 群以上）
・値の性質（較正していない相対的な画像強度）
```

バンド画像を Figure に使うときの約束（本アプリのバンド画像パネルの仕様）：

```
・元画像の連続した矩形だけを切り出す（レーンの並べ替え・継ぎ合わせをしない）
・画像ごとに別の段にし、タンパク質・画像・膜・露光を表示する（境界を隠さない）
・表示は線形の変換（下限と上限の 2 値）だけ。ガンマ補正や部分的な明るさ調整をしない
・切り出し座標・表示レベル・元画像のハッシュを記録し、切り出した画素を元の値のまま保存する
・原画像ファイルは変更しない
```

再現のために記録すべきもの（本アプリが解析レポートに保存する内容）：

| 項目 | 例 |
|---|---|
| 原画像 | ファイル名、ハッシュ値（内容が変わっていないことの確認）、bit 深度、形式 |
| 取り込み条件 | スキャナー機種、透過／反射モード、解像度、自動補正の有無、露光時間 |
| ROI | レーン・バンド・背景 ROI の座標と大きさ |
| 定量設定 | 極性、背景法とパラメータ（gap、height）、測定値（補正前積分値、背景値、S、画素数） |
| 試料情報 | sample_id、group、bio_rep、tech_rep、subject_id、batch_id、膜 ID、露光 ID |
| 判断 | 除外したバンドと理由、QC 警告への判断 |
| 解析 | 正規化の分子・分母・対照群、検定に使った値（比／log2）、検定名、多重比較の調整、ソフトウェアのバージョン |
| Figure | エラーバーの種類、図の説明文、バンド画像の切り出し座標と表示レベル |

## (5) 具体例

**教材用合成データ**（実験由来ではありません）。8-bit、背景 220、深さ 40, 80, 120, 160 の 4 本のバンド（ROI 220 画素、近傍背景で補正）。原画像での S は 8800, 17600, 26400, 35200（比 1 : 2 : 3 : 4）。

この画像に表示調整をかけ、**調整後の画像を保存して定量してしまった**場合：

| 画像 | 変換 | S（バンド 1〜4） | 1 本目との比 |
|---|---|---|---|
| 原画像 | なし | 8800, 17600, 26400, 35200 | 1 : 2 : 3 : 4 |
| 直線的な調整 | p' = (p − 50) × 255 ÷ 170 | 13200, 26400, 39600, 52800 | 1 : 2 : 3 : 4 |
| ガンマ補正 | γ = 2.0 | 13860, 24860, 33220, 38720 | 1 : 1.79 : 2.40 : 2.79 |
| 強いコントラスト | p' = (p − 100) × 255 ÷ 100、0〜255 に切り詰め | 11220, 33660, 56100, 56100 | 1 : 3 : 5 : 5 |

（数値は make_blot・estimate_background・measure_band で検算済み）

- 直線的な調整では S は 1.5 倍になったが、比は保たれた。ただし背景がちょうど 255 になったため、この画像は QC の「白飛び候補」にかかる。少し強ければ背景が切り詰められ、比が崩れる。
- ガンマ補正では、濃いバンドほど差が縮み、比が歪んだ。
- 強いコントラストでは、背景が 255 に、濃い 2 本が 0 に切り詰められ、バンド 3 と 4 の区別が失われた。

本アプリでは、表示の明るさ・コントラスト・Invert は表示用コピーにだけかかり、定量には常に原画像が使われます。Figure 用のバンド画像の切り出しも、元画像を変更せずコピーから作ります。

**SD・SEM・95% 信頼区間の比較**（教材用合成データ。値 0.90, 1.00, 1.10、n = 3。wbtool.core.figure.error_half_width で検算済み）：

| エラーバー | 平均 1.00 からの幅 | SD に対する長さ |
|---|---|---|
| SD | 0.100 | 1 |
| SEM | 0.100 ÷ √3 = 0.058 | 約 0.58 倍 |
| 95% 信頼区間 | 4.303 × 0.058 = 0.248 | 約 2.5 倍 |

同じ 3 点でも、SEM なら短く、95% 信頼区間なら長く見えます。同じ SD で n = 12 なら、SEM は 0.029、95% 信頼区間の幅は 2.201 × 0.029 = 0.064 です。SEM と信頼区間は n が増えると縮みますが、SD（データのばらつき）は縮むとは限りません。

**Figure の例**：5 章の例 1（Control・Treated 各 n = 3）をグラフにするなら、

- 各生物学的反復の fold を点で描き、平均（と SD または 95% CI）を重ねる。
- 図の説明に「n = 3 生物学的反復（各 2 技術的反復の平均）」「平均 ± SD」「検定：Welch の t 検定」と書く。本アプリが作る説明文の例：「縦軸：対照群を 1 とした相対値（fold change）。点は個々の生物学的反復（biological replicate）、平均 ± SD を示す（Control n = 3, Treated n = 3）。技術的反復（technical replicate）は生物学的反復ごとに平均した。…」
- 技術的反復 12 点を全部描いて n = 6 に見せたり、SEM を説明なしに使って誤差を小さく見せたりしない。
- バンド画像を添える場合は、定量に使った露光の画像を使い、元画像の連続した範囲を切り出す。別の膜・別の露光の画像は別の段にして境界を示す。

## (6) 小問

**問 1.** バンドが見づらかったので、画像編集ソフトでガンマを調整して上書き保存し、その画像を定量した。何が問題ですか。どうすればよかったですか。

**問 2.** 直線的な調整 p' = 2 × p − 100（切り詰めが起こらない範囲）をかけた画像で、背景補正後の S が原画像の何倍になるか答えなさい。バンド間の比はどうなりますか。

**問 3.** 同じ実験の Target を 2 枚の膜で流し、それぞれの見栄えのよいレーンを切り貼りして 1 枚の図にしたい。何に注意すべきですか。

**問 4.** ある学生が、エラーバーを SD から SEM に変えたら「群の差がはっきりして見える」と喜んでいます。n = 3 のとき、SEM のバーは SD のバーの何倍の長さですか。この変更の何が問題ですか。

**問 5.** 図の説明に「Data are mean ± error.」とだけ書かれています。読み手が知りたいのに分からないことを 3 つ挙げなさい。

## (7) 解答・解説

**問 1.** 二つの問題があります。(a) ガンマ補正は曲がった変換なので、バンド間の比が変わります（具体例では 1 : 2 : 3 : 4 が 1 : 1.79 : 2.40 : 2.79 になった）。(b) 上書き保存で原画像が失われ、元の値で測り直すことも、第三者が検証することもできなくなりました。見やすくするのは表示上だけにし、定量は原画像で行います。原画像は読み取り専用の場所にも保管しておきます。

**問 2.**

```
S' = −Σ ((2 × p_i − 100) − (2 × b − 100)) = 2 × ( −Σ (p_i − b) ) = 2 × S
```

S は 2 倍になりますが、すべてのバンドが同じく 2 倍なので比は変わりません。ただし実際には 0〜255 の範囲を超えた部分が切り詰められやすく、その場合は比が崩れます。安全なのは、そもそも調整した画像で定量しないことです。

**問 3.** 別の膜（露光・転写条件も異なり得る）の S を、膜間の正規化なしに直接比べることはできません。図では境界線を入れて別の膜であることを示し、図の説明と方法に記載します。見栄えでレーンを選ぶのではなく、事前に決めた基準で選び、選ばなかったレーンも含めて原画像を保存します。共通参照レーンなどを使った膜間正規化は本アプリでは未実装です。本アプリのバンド画像パネルは、レーンの並べ替え・継ぎ合わせをせず、画像ごとに別の段で表示し、膜と露光を各段に書きます。

**問 4.**

```
SEM ÷ SD = 1 ÷ √3 ≈ 0.58
```

SEM のバーは SD の約 0.58 倍の長さです。SEM は「平均の推定精度」で、データのばらつきを表す SD とは別の量です。差を大きく見せるために後から選ぶのは誤解を招きます。どちらを使うかは目的で決め（データのばらつきを見せるなら SD）、図の説明に必ず種類を書き、個々の点も一緒に示します。

**問 5.** 例えば次のことが分かりません。(a) エラーバーが SD・SEM・95% 信頼区間のどれか。(b) 各群の n と、その単位（生物学的反復か、技術的反復を含むか）。(c) 使った検定と、p 値が多重比較で調整済みか。ほかに、縦軸の値の定義（何で正規化し、何を 1 としたか）も必要です。

**このアプリでの操作：** ［Figure］画面でエラーバー（SD／SEM／95% 信頼区間）を選び、必要なら［統計］の調整済み p 値を表示します。右下の「図の説明文」をコピーして編集しましょう。「バンド画像＋グラフ（複合）」タブでは、元画像の連続した領域を切り出したバンド画像パネルを作れます。保存すると、切り出し座標・表示レベル・元画像のハッシュの記録（JSON）と、切り出した原画素の TIFF も残ります。定量値・説明文・設定は「図のデータ・説明文・設定を保存」で CSV／TXT／JSON に書き出し、原画像と一緒に保管しましょう。
